**To download a file:** open it on GitHub and click the **Download raw file** button (⤓, top right of the file view). Every file is complete; there are no parts to join.

- **Windows:** this is the portable app. Replace your old `Mind It!.exe` with this one; your data stays.
- **Galaxy Tab:** open the APK on the tablet and tap **Update**. It is signed with the original key (versionCode 125), so it installs over the old app and keeps its data.
- **Mac:** see `Mac/How to install on a Mac.txt`. Not yet tried on a real Mac. Test it at home before a quiz night.

## New in build 125

- 🗑 **Recently Deleted**: bring a deleted player back (profile, picture and statistics) for 30 days.
- 🛟 **Safety backups**: made automatically just before a backup is restored, players or a game record are deleted, or you Start fresh. The last 10 are listed in Backups & Restore.
- ☑ **Select** several players to archive or delete them together.
- The **tablet keeps what you're typing** (Adjust Score and other boxes) when the laptop changes the scores.
- 🖼 **Results Picture** for any game in Historic Games.
